# GMH Rozvrh

Jednoduchá webová aplikace pro studenty a učitele Gymnázia Mnichovo Hradiště. Zobrazuje aktuální i následující rozvrh a automaticky načítá dostupné třídy, učitele a skupiny z Bakalářů.

Projekt vyvinul **Eduard Wojnar** pro **Gymnázium Mnichovo Hradiště**.

## O projektu

GMH Rozvrh vznikl jako přehlednější a pohodlnější způsob, jak si rychle zobrazit školní rozvrh. Data se pravidelně aktualizují pomocí scraperu a ukládají se do cache, aby byla aplikace rychlá.

Scraper používá veřejné stránky [Bakalářů Gymnázia Mnichovo Hradiště](https://znamky.gmh.cz/Timetable/Public).
